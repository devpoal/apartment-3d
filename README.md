# Квартира · интерактивная 3D-планировка

Модель квартиры площадью 43,2 м² с мебелью, отделкой по референсам, детской с двумя кроватями и кухней-гостиной. Размеры восстановлены по фотографии плана; высота потолка — 2,70 м. Это концепция, требующая обмеров перед ремонтом и заказом мебели.

[Посмотреть опубликованную модель](https://apartment-736-view-3d.devpoal.chatgpt.site/?view=public)

## Посмотреть локально

Откройте `index.html` в современном браузере с WebGL. Интернет для самой модели не требуется: библиотека и вся геометрия включены в страницу.

Перетаскивание вращает модель, колесо меняет масштаб. Список помещений позволяет рассмотреть отдельные комнаты. Есть вид сверху, показ полных стен и открывание гардеробной.

## Изменить и собрать

Установите Node.js 18 или новее. Дополнительные пакеты не нужны.

```sh
npm run build
```

Команда проверяет размеры и размещение мебели, обновляет `index.html` и экспортирует модель в `dist/apartment-wall.glb`. Проверки также доступны через `npm test`.

## Файлы проекта

- `model.js` — стены, мебель, материалы и размеры. Все размеры заданы в метрах.
- `viewer.js` — управление камерой, выбор помещений и взаимодействия.
- `fragment.html` — элементы управления просмотром.
- `build.cjs` — сборка страницы, проверки геометрии и экспорт GLB.
- `index.html` — готовая автономная страница; хранится в репозитории для удобного просмотра и размещения.
- `vendor/` — Three.js r128 и OrbitControls. Лицензия зависимостей находится в `vendor/LICENSE.three.txt`.

Публикация текущего сайта выполняется отдельно. Изменения в этом репозитории сами по себе не обновляют размещённую модель.

В проект не включены исходные фотографии, локальные настройки Sites и данные подключения к сервисам.
